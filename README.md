# Nook — AI Marketing Studio

> **IBM AI Builders Challenge · July 2025 · Theme: Reimagine Creative Industries with AI**
> Built with IBM Bob as the primary development tool.

---

## The Problem

Small business owners know what they want to say — they just can't say it well, fast, or across every platform at once.

A bakery owner knows their product is great. A freelance photographer knows who their clients are. But when it comes to writing a Facebook post, an email campaign, a LinkedIn update, and a blog intro — all with consistent tone, a clear call to action, and the right hashtags — most give up or post something generic.

Existing AI writing tools make this worse, not better. You get one text box, one prompt, one result. If it's wrong you start again from scratch. Nothing remembers your brand voice. Nothing knows your audience or your goal. Nothing produces a complete, ready-to-use package across platforms in one go.

---

## The Solution

**Nook** is a guided AI marketing studio that turns a 6-question conversation into a complete, multi-platform campaign — powered by IBM watsonx Granite.

Instead of asking small business owners to write prompts, Nook asks plain questions:

1. What's your business name?
2. What industry are you in?
3. Who is your target audience?
4. What's your campaign goal?
5. What's your brand tone?
6. Which platform is your primary channel?

From those six answers, IBM watsonx Granite generates a **full campaign package** in a single structured call:

| Output | Description |
|---|---|
| **Facebook post** | Engaging copy with emoji and CTA |
| **Instagram caption** | Short, visual-first with hashtags |
| **LinkedIn post** | Professional tone, value-led |
| **Email** | Subject line + body copy |
| **Blog post draft** | Opening section with hook |
| **Call to action** | One clear action for any channel |
| **SEO keywords** | 5 keywords for the campaign |
| **Hashtags** | 5 ready-to-use hashtags |
| **Image prompts** | 3 visual concepts for the designer |

Every piece is copyable individually or as a single text export. The whole process takes under 2 minutes.

## AI Approach and Architecture

### Why watsonx

IBM watsonx Granite is the core intelligence engine. It is not a wrapper — every campaign is generated by a single structured prompt sent to the Granite model via the watsonx.ai REST API, returning a validated JSON object with 11 fields.

```
User answers 6 intake questions
           │
           ▼
  Flask backend (Python)
  workflow.py → handle_message()
           │
           ▼
  Prompt is built from the 6 answers
  (business name, industry, audience,
   goal, tone, platform)
           │
           ▼
  watsonx_client.py → generate_campaign()
  POST /ml/v1/text/generation
  Model: ibm/granite-13b-chat-v2
  max_new_tokens: 1800
           │
           ▼
  JSON response parsed and validated
  Falls back gracefully if JSON is malformed
           │
           ▼
  Campaign dashboard rendered in browser
  (5 platform cards + SEO + hashtags + image prompts)
```

### Architecture decisions

| Component | Choice | Reason |
|---|---|---|
| AI model | IBM watsonx Granite (granite-13b-chat-v2) | Required IBM tech doing real work, not decoration |
| Prompt strategy | Single structured JSON prompt | One call = full campaign; avoids chaining latency |
| Backend | Python / Flask | Lightweight, easy to run locally, no overhead |
| Session storage | SQLite (session_store.py) | Persists session across page refreshes; 4-hour TTL with background eviction |
| Rate limiting | Flask-Limiter (30 req/min) | Protects against abuse during demo |
| Token caching | In-memory IAM token cache | Eliminates a round-trip on every generate() call |
| Mock mode | `WATSONX_USE_MOCK=true` default | Lets judges run it without credentials; rich mock responses |
| Frontend | Vanilla HTML/CSS/JS | Zero build step; judges can clone and run in 30 seconds |

### IBM Bob's role

IBM Bob was the **primary development tool** throughout the entire build:

- **Plan mode** — used to decompose the spec into a concrete implementation plan: session state machine, intake flow, watsonx API integration, frontend rendering pipeline
- **Agent mode** — used to scaffold all Python modules (`workflow.py`, `watsonx_client.py`, `session_store.py`, `app.py`), fix three critical bugs found during audit (broken `generate_campaign` function, `self` vs `session` reference error in `session_store._write`, wrong answer key mapping in `workflow.handle_message`), and build the complete frontend from scratch
- **Iterative UI upgrades** — Bob rebuilt the frontend twice in response to design feedback: first to a premium light-mode studio layout, then to add the dark hero welcome screen with animated orbs and the IBM watsonx Granite badge on the campaign output
- **Code verification** — Bob audited every file, identified all bugs before they caused runtime failures, and ran smoke tests after each change

## Challenge Theme

**Reimagine Creative Industries with AI**

Nook addresses three of the solution areas from the challenge brief:

- **AI Creative Partners** — Nook works *with* the user through a guided dialogue, not a single prompt box. It acts as a creative collaborator that knows the business context.
- **Storytelling & Content Creation** — The output is not generic filler. Each platform's copy is written for that platform's tone and format, with a consistent brand voice set by the user.
- **Interactive & Personalized Experiences** — The campaign is personalised to the specific business, audience, goal, tone, and platform answered in the intake. No two campaigns are the same.

- Python 3.10+
- An IBM Cloud account with watsonx.ai access (or run in mock mode without one)

```bash
git clone https://github.com/chavel88-ship-it/nook.git
cd nook
pip install -r requirements.txt
python app.py
```

Open [http://localhost:5000](http://localhost:5000) — the app runs in mock mode by default, generating realistic demo campaigns without hitting the real API.
